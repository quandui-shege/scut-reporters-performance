# 华工学生记者团绩效统计系统

用于记者团个人与部门的月度绩效统计，支持成员管理、AI 工作描述整理、批量加分、绩效明细核对，以及 Excel 导出和数据交接。

本项目为本地网页版，无需安装。分享版初始数据为空，不包含成员名单、绩效记录或 API Key。

## 快速开始

1. 在仓库页面点击 **Code → Download ZIP**，下载项目。
2. 解压整个压缩包，保留文件和子文件夹的原有结构。
3. 双击 **开始使用.html** 或 **index.html**，进入系统。
4. 首次打开时，可填写自己的 DeepSeek API Key，也可先离线查看。使用 AI 整理时需要密钥和网络连接。
5. 点击右上角 **使用指南**，查看操作步骤。

## 主要功能

| 模块 | 功能 |
| --- | --- |
| 主页 | 提供各功能的快捷入口 |
| 个人绩效 | 按月份新增或导入成员，查看个人分数和绩效细则 |
| 部门绩效 | 查看部门分数、成员及部门绩效细则 |
| 绩效统计 | 个人加分、个人批量加分、部门加分及手动选择规则加分 |
| 任务与交接 | 导出 Excel、导出和导入数据包、查看与移除导入记录 |
| 绩效规则 | 查看和调整个人、部门的加分项目与规则 |

## 使用流程

### 1. 准备当月名单

在 **个人绩效** 中选择月份，新增成员或导入 Excel 名单。

名单表头为：

| 姓名 | 部门 | 职务 |
| --- | --- | --- |

职务支持部长、副部长、部员；主席团使用团长。空白模板位于 **模板** 文件夹，也可以在系统中下载。

每个月的名单独立保存。新月份需要重新新增或导入名单，修改一个月份不会同时修改其它月份。

### 2. 登记绩效

进入 **绩效统计**，先选择统计月份。

- **个人绩效加分**：点击选择成员，先选部门，再选姓名；工作描述每行填写一个项目，点击整理并预览，检查内容与规则后确认加分。
- **个人绩效批量加分**：导入以下三列的 Excel，每行一位成员，工作描述单元格内可以换行填写多个项目。

| 部门 | 姓名 | 工作描述 |
| --- | --- | --- |

- **批量核对**：明确识别的项目确认后计入绩效；不明确的项目留在批量页面的核对问题中，补选规则并确认后计分。
- **部门绩效加分**：选择部门，填写工作描述，整理预览后确认。
- **手动加分**：选择对象后点击手动加分，先选加分项目，再选具体规则并填写内容。个人规则中的 **其它内容 → 手动加分** 可自行填写本次分值。

绩效归入所选择的统计月份，无需单独核对描述中的日期。一次加分完成后，选择对象和工作描述会清空。

### 3. 查看与移除记录

在个人或部门的 **绩效细则** 中查看加分明细。移除一条记录需要再次确认，相关分数会同步重新计算。

职务分不能移除，运营部固定活动加分可以移除。仅有这两类固定分时不会锁定名单；存在其它绩效记录时，对应成员或部门名单会锁定。

### 4. 导出与交接

在 **任务与交接** 中操作：

- **导出个人绩效 Excel**：先选月份，再通过按钮多选部门。输出一个 Excel，每个部门单独一张工作表。
- **导出部门绩效 Excel**：先选月份，再多选部门。所选部门汇总到同一张工作表。
- **导出数据**：个人与部门分别导出 ZIP 数据包，用于备份或转移到另一台电脑。
- **导入数据**：选择对应类型的数据包，恢复其中的月份、部门、绩效明细、规则及相关资料。已有对应范围的数据时会提示确认替换，其它范围的数据保留。
- **查看导入记录**：个人与部门分别查看。每次导入是一条大记录，其中包含具体的小记录；两者均可移除，移除需再次确认，相关导入数据和绩效同步删除。

## 数据保存

已保存的数据会保留在当前浏览器本地。未提交的加分输入草稿刷新后清空，已保存的批量待核对事项可以继续处理。

项目内提供 **数据** 文件夹：

```text
数据/
├── 导出表格/    Excel 绩效表
├── 备份数据/    ZIP 数据包
└── 月度存档/    按月份保存的绩效数据和完整存档
```

在 **任务与交接 → 选择数据文件夹** 中选择该文件夹，并允许浏览器读写。连接后，导出文件和月度存档会写入对应目录。

重新打开系统后需再次连接文件夹；如果已有完整存档，系统会询问是否恢复。浏览器不支持文件夹写入或未连接时，仍可正常下载导出文件，请自行保存到对应目录。

清除浏览器数据会清除浏览器中的本地存档。需要备份或更换电脑时，请先导出数据包。

## API Key

- 点击左下角 **API Key 设置**，填写自己的 DeepSeek API Key。
- 密钥单独保存在当前浏览器本地，下次打开无需重新填写。
- 密钥不写入导出的 Excel、数据包或文件夹月度存档。
- AI 整理会向 DeepSeek 发送所需的工作描述、姓名、部门和计分规则；分数由系统规则计算。
